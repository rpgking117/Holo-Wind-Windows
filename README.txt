WHAT THIS MOD DOES
------------------
Holo-Wind renders The Elder Scrolls III: Morrowind live inside the Fallout 4
Pip-Boy screen using a modified build of OpenMW 0.50. When you insert the
Morrowind holotape in-game, OpenMW launches and displays Pip-Boy display in real time.

================================================================================
!! IMPORTANT — BACKUP YOUR OPENMW SETTINGS BEFORE INSTALLING !!
================================================================================

This installer OVERWRITES your OpenMW user configuration files:

  %USERPROFILE%\Documents\My Games\OpenMW\settings.cfg
  %USERPROFILE%\Documents\My Games\OpenMW\input_v3.xml
  %USERPROFILE%\Documents\My Games\OpenMW\shaders.yaml

The installer forces a fixed 876x700 windowed resolution and disables the
cursor and crosshair so OpenMW can be streamed to the Pip-Boy. These settings
WILL prevent OpenMW from launching correctly for normal standalone play.

  BEFORE RUNNING THE INSTALLER:
  Copy the entire folder
      %USERPROFILE%\Documents\My Games\OpenMW\
  somewhere safe (e.g. your Desktop) so you can restore it later if needed.

To restore normal OpenMW after using the mod, copy your backup back to that
folder and remove the read-only flag from settings.cfg.

================================================================================
REQUIREMENTS
================================================================================

  - Windows 10 or 11 (64-bit)
  - Steam installed
  - Fallout 4 (Steam)
  - The Elder Scrolls III: Morrowind (Steam)
  - F4SE (Fallout 4 Script Extender)
      Download: nexusmods.com/fallout4/mods/42147
      F4SE MUST be installed before launching the mod.

================================================================================
HOW TO INSTALL
================================================================================

  1. Back up your OpenMW settings folder (see above).
  2. Run HolloWindSetup.exe as Administrator (it will prompt if needed).
  3. Click INSTALL and wait for all steps to complete.
  4. Install F4SE from Nexus Mods if you haven't already.

================================================================================
HOW TO PLAY
================================================================================

  1. Launch Fallout 4 via f4se_loader.exe (NOT the normal launcher).
  2. Load any save — the Morrowind Holotape can be added by opening console and typing "help morrowind 4" and then using player.additem XX000800.
  3. Open your Pip-Boy and go to the MISC section.
  4. Select and insert the Morrowind Holotape.
  5. Once inserted Morrowind launches and appears on the Pip-Boy screen - always use the Tab key to exit the game. 
  6. Press Tab, to close Morrowind and return to Fallout 4.
